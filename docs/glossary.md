# Glosario

Vocabulario compartido del dominio y del proyecto. Mantén las definiciones cortas
y sin ambigüedad para que todo el equipo use los términos de la misma forma.

| Término           | Definición                                                                                       |
| ----------------- | ------------------------------------------------------------------------------------------------ |
| Web API           | Interfaz nativa que el navegador expone a JavaScript (DOM, Canvas, Geolocation, etc.).            |
| Ejemplo / demo    | Una página de `pages/` con su script en `src/js/` que ilustra una Web API concreta.              |
| Design token      | Variable CSS de la marca (color, etc.) definida en `styles.css` y reutilizable en todo el sitio. |
| Tema (theme)      | Modo visual claro u oscuro, controlado por el atributo `data-theme` en `<html>`.                 |
| Contexto seguro   | Origen `https://` o `localhost`; requisito de varias APIs (cámara, portapapeles, notificaciones).|
| Feature detection | Comprobar en tiempo de ejecución si el navegador soporta una API antes de usarla.                |
| `.output-area`    | Contenedor estándar donde cada ejemplo muestra su resultado o mensajes al usuario.               |

> Convención: ordena los términos alfabéticamente y enlaza al documento donde se
> detalla cada concepto cuando aplique.
