Demostración de Web APIs

Explora ejemplos prácticos e interactivos de las principales APIs nativas del navegador. Solo HTML, CSS y JavaScript — sin backend ni dependencias.

DOM

Canvas

Dibuja gráficos, elige color y grosor de línea, y crea ilustraciones interactivas en 2D.

Red
